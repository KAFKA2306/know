# 研究判断

調査で下した判断と、判断に使った観測・一次資料をまとめています。数値や制度を使い直すときは、記事の確認時点と再確認条件を確かめてください。

| 調べること | 記事で確かめられる判断 |
| --- | --- |
| [米国の電力供給](../dev/deepdive/us-electricity-supply.md) | 発電、設備容量、送電の制約を分けてみる。 |
| [カリフォルニア州の自動運転報告](../dev/deepdive/california-av-reporting-2026.md) | 新旧の報告指標をつながない。2026年9月10日時点の制度メモ。 |
| [製造の品質検査](../dev/deepdive/manufacturing-quality-inspection.md) | 検査対象、検査範囲、導入段階をそろえて比べる。 |
| [再使用ロケット](../dev/deepdive/reusable-launch-evidence.md) | 打上げ実績と、機体・段の再使用の証拠を区別する。 |

複数のリポジトリで判断の根拠を記録するには、[根拠の記録と検証の導入ガイド](../services/evidence-contract-integration.md)を参照してください。
