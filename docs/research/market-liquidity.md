# 米国流動性・AI投資・富裕層消費

**整理日：2026年11月21日。状態：仮説検証中。** これはリアルタイム指標でも売買シグナルでもない。数値を使うときは必ずリンク先の公表日と対象期間を再確認する。

## 判断

「AI設備投資が利益を生む前に資金調達の買い手が不足し、その影響が株式市場へ波及する」「富裕層の消費が弱まり、高級品や高級住宅から業績へ伝播する」は、どちらも**未判定の仮説**とする。

金利上昇と発行量の制約は同じではない。株価下落、高級品売上、資金調達の悪化が同時に起きても、因果関係は自動的には証明されない。

## 追跡する仮説

| 仮説 | 観測するもの | 反証・別解の候補 |
| --- | --- | --- |
| AIの資金調達が「金利」より「買い手不足」で詰まる | 提示利回り、調達希望額と成立額、発行延期・撤回、投資家需要 | 価格が上がれば調達が成立する。発行延期は案件固有の信用問題 |
| データセンター起債が信用市場を圧迫する | 同格付け・同年限のスプレッド、発行量、他業種の調達条件 | 市場全体の信用悪化や金利変動で説明できる |
| 富裕層消費の鈍化が広がる | 高級品各社の地域別・部門別売上、数量と為替、米国高級住宅の成約 | 為替・商品構成・供給制約・比較基準の変化 |
| 消費鈍化が指数企業の利益へ波及する | BEAの個人消費、企業の売上・利益率・ガイダンス | 高所得層と総消費の動きが一致しない |

**禁止する短絡：** LVMHの Watches & Jewelry の売上をTiffany単体の実績と呼ばない。コンドミニアムの売出価格を成約価格と呼ばない。資金調達希望額と成立額を同一の定義なしに割り算しない。

## 一次資料から調べる { #primary-sources }

| 区分 | 一次資料 | 読み方 |
| --- | --- | --- |
| 金融安定性 | [FRB Financial Stability Report（2026年11月）](https://www.federalreserve.gov/publications/financial-stability-report.htm) | 公表日とデータの対象時点を区別する |
| 資金市場 | [NY連銀 SOFR](https://www.newyorkfed.org/markets/reference-rates/sofr) | 短期調達金利。資金調達の「量」そのものではない |
| 信用スプレッド | [FRED：米ハイイールドOAS](https://fred.stlouisfed.org/series/BAMLH0A0HYM2) | 市場全体の指標。個別DC案件の条件とは別に記録する |
| DC資金調達 | [FRB・2026年10月FOMC議事要旨](https://www.federalreserve.gov/monetarypolicy/fomcminutes20261028.htm) | データセンター関連起債と信用市場への言及を原文確認する |
| 消費全体 | [BEA 個人消費支出](https://www.bea.gov/data/consumer-spending/main) | 名目・実質、月次・前年比、改定を混同しない |
| 高級品 | [LVMH 投資家向け開示](https://www.lvmh.com/investors/investors-and-analysts) | Fashion & Leather Goods、Watches & Jewelryを分け、Tiffany単体とは区別する |

## 手順と記録形式

1. 発行元、原典URL、公表日、対象期、通貨、単位、改定番号を記録する。
2. 「観測した数値」「計算した変化」「発信者の主張」「自分の仮説」を別の列にする。
3. 同格付け・同地域・同時期の対照群を置く。調達事例は成立しなかった案件も集める。
4. 先に反証条件を決める。条件がそろわなければ**未判定**のまま残す。
5. 企業と指数を分ける。指数に関する判断では、個別銘柄の話をそのまま指数の利益予測にしない。

| 項目 | 例 |
| --- | --- |
| 観測 | 「FRB議事要旨にDC向け信用スプレッドへの言及がある」 |
| 推定 | 「同条件の企業全体で発行が難しくなっている」 |
| 判定 | 比較できる発行条件と件数がそろうまで未判定 |
| 更新契機 | 次の統計改定、企業決算、資金調達案件の条件開示 |

## 反証と再確認条件 { #falsification }

- 高級品の数量・米国売上が持ち直す、または他地域・為替要因だけで減収が説明できるなら、富裕層失速仮説を弱める。
- 調達案件が同条件の市場価格で成立するなら「量的な買い手不足」という主張を修正する。
- 公式決算と発行資料が欠ける案件について、噂・動画の主張を確定事実として記載しない。

**次の判断：** まず「信用市場全体」と「AI/データセンター案件」、「消費全体」と「高所得層」を独立に追跡し、両者をつなぐ前に反証を試す。
